# afriendlywave.com

A website for the Salt Spring listening space. We poll Mixcloud for new shows and rebuild the static Astro site when one is published.

## Project guidance

See [AGENTS.md](AGENTS.md) for development conventions and [docs/identity.md](docs/identity.md) for visual identity guidance.

## Requirements

- Node.js 22+
- pnpm

## Development

```sh
pnpm install
pnpm dev
```

Open http://localhost:4322.

## Build

```sh
pnpm build
pnpm preview
```
