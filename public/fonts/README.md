# Iosevka

Regular (400) and bold (700) WOFF2 fonts from the official Iosevka v34.9.0 release:
https://github.com/be5invis/Iosevka/releases/tag/v34.9.0

Source archive: `PkgWebFont-Unhinted-Iosevka-34.9.0.zip`.
Files extracted unchanged from `WOFF2-Unhinted/Iosevka-Regular.woff2` and
`WOFF2-Unhinted/Iosevka-Bold.woff2`, with lowercase filenames for local serving.

Iosevka Aile Heavy (900) comes from the same release's
`PkgWebFont-Unhinted-IosevkaAile-34.9.0.zip` archive, extracted unchanged from
`WOFF2-Unhinted/IosevkaAile-Heavy.woff2` as `iosevka-aile-heavy.woff2`.
Used for headings via `font-heading font-black`.
